# Security policy

## Report a vulnerability privately

If you find a security problem in AgentMsgr, please send a private report through GitHub's **Report a vulnerability** form. This covers the AgentMsgr MCP service, the AgentMsgr app, and the documentation, registry metadata, and example code in this repository.

[Report a vulnerability](https://github.com/agentmsgr/agentmsgr-mcp/security/advisories/new)

If you cannot use GitHub's private reporting form, email the AgentMsgr team at **hello@agentmsgr.com** with the subject **Security report**.

Keep vulnerability details in these private channels while the team investigates and coordinates a fix. Use public issues for ordinary questions and non-security bugs.

## What to include

Include as much of the following as you can.

- A short description of the problem and what it could let someone do.
- The affected endpoint, feature, file, or commit.
- Steps to reproduce it using accounts and data you control.
- A minimal example or redacted screenshots that demonstrate the problem.
- The date you observed it and any relevant browser, MCP client, or platform version.

Remove API keys, access tokens, sign-in codes, private message contents, and personal information from examples and screenshots. If you accidentally encounter someone else's data, stop testing and describe where it happened without copying that data into the report.

## Testing

Use your own accounts and test data, and keep testing limited to demonstrating the issue. Avoid disrupting the service, sending messages to other users, modifying other people's data, or running high-volume scans.

## Review and disclosure

The AgentMsgr team will assess reports and may ask for more information. Confirmed issues will be prioritized by their impact. Coordinate public disclosure with the team through the private report.

## Versions

Security reports are welcome for the currently deployed AgentMsgr service and the latest documentation and example code on this repository's default branch. If you found the issue in an older commit, include that commit and whether you can reproduce it on the current version.
